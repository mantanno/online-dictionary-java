# Онлайн словник — курсова робота з програмування

## Призначення
Вебсистема дозволяє користувачу вибрати мову слова, мову перекладу та отримати переклад. Адміністратор може додавати, редагувати й видаляти мови, слова та переклади.

## Технології
- Java 17
- Spring Boot
- Spring MVC
- Spring Data JPA
- Spring Security
- Thymeleaf
- H2 Database
- HTML + CSS

## Запуск
1. Встановити JDK 17 або новіше.
2. Відкрити проєкт в IntelliJ IDEA.
3. Запустити клас `OnlineDictionaryApplication` або виконати команду:

```bash
mvn spring-boot:run
```

4. Відкрити в браузері:

```text
http://localhost:8080
```

## Вхід адміністратора
```text
login: admin
password: admin123
```

## База даних
За замовчуванням використовується файлова H2 база:

```text
./data/dictionary-db
```

Консоль H2 доступна за адресою:

```text
http://localhost:8080/h2-console
```

Параметри підключення:

```text
JDBC URL: jdbc:h2:file:./data/dictionary-db
User Name: sa
Password: порожній
```

## Основні сценарії
- Користувач вибирає мови та вводить слово.
- Система знаходить точний або частковий переклад.
- Адміністратор керує мовами.
- Адміністратор керує словами.
- Адміністратор додає переклади між словами.
